HOW IT WORKS
================================================================================

FORMULA 1: Convert Speed to Delay
  delay_seconds = 1 / requestsPerSecond
  
  Example: requestsPerSecond = 2
  Result: delay_seconds = 1/2 = 0.5 seconds between requests

FORMULA 2: Calculate Concurrent Requests
  max_concurrent = Math.min(Math.max(Math.ceil(requestsPerSecond), 1), 50)
  
  Example: requestsPerSecond = 2
  Result: max_concurrent = 2 (can run 2 requests in parallel)

IMPLEMENTATION: Semaphore-based Control
  semaphore = asyncio.Semaphore(max_concurrent)
  async with semaphore:
      response = await client.get(url)
  await asyncio.sleep(delay_between_requests)
