REQUEST FLOW DIAGRAMS
================================================================================

Session Creation Flow:
POST /api/v1/gateway/auth/session
  ↓ (CreateSessionRequest)
verify_firebase_token()
  ↓ (Firebase ID Token)
ProfileService.fetch_user_profile()
  ↓ (User UID)
SessionService.create_session()
  ↓ (User Data + IP + User-Agent)
Set secure cookie (httpOnly, secure, SameSite)
  ↓
Return user data (uid, email, name, picture)

User Profile Flow:
GET /api/v1/gateway/configuration/users/profile
  ↓
get_current_user() [dependency]
  ↓ (Session validation)
AuthDAO.get_user_by_role_id()
  ↓ (User ID)
Query database
  ↓
Return profile data

Configuration Data Flow:
GET /api/v1/gateway/configuration/data/{endpoint}
  ↓
ConfigurationService.get_{endpoint}()
  ↓
ChatAgentConfigDAO.get_{endpoint}()
  ↓
Query database
  ↓
Return formatted response

QUICK START
================================================================================

1. Install Dependencies:
   $ cd knowledgebot-railway-backend
   $ pip install -r tests/requirements-test.txt
   $ pip install -r configuration/requirements.txt
   $ pip install -r api_gateway/requirements.txt

2. Run All Tests:
   $ pytest tests/auth/ tests/configuration/test_configuration_data_endpoints.py -v

3. Run with Coverage:
   $ pytest tests/auth/ tests/configuration/test_configuration_data_endpoints.py -v --cov=api_gateway --cov=configuration --cov-report=html

   $ open htmlcov/index.html
